# CRISP: Test Plan

**Use when:** You need a test plan drafted from scratch.

| Part | Content |
|------|---------|
| **C**ontext | Project {{project_name}}, release {{release}}, scope/requirements: <url> |
| **R**ole | QA lead |
| **I**nstruction | Draft a test plan |
| **S**pecifics | Scope, out of scope, test types ({{test_types}}), entry/exit criteria, risks, schedule |
| **P**arameters | Audience {{audience}}, under {{pages}} pages |

## Copy-paste prompt
```
Context: Project {{project_name}}, release {{release}}. Scope and requirements: <url>.
Role: You are a QA lead.
Instruction: Draft a test plan.
Specifics: Include scope, out of scope, test types ({{test_types}}), entry and exit criteria, risks with mitigations, schedule ({{start_date}} to {{end_date}}), and roles.
Parameters: Audience is {{audience}}. Keep it under {{pages}} pages. Use "TBD" for anything unknown.
```
