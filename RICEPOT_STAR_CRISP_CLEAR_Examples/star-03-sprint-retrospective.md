# STAR: Sprint Retrospective (QA)

**Use when:** You want lessons learned from a sprint turned into improvements.

| Part | Content |
|------|---------|
| **S**ituation | Sprint {{sprint}} outcomes: planned {{planned}}, completed {{completed}}, defects {{defect_count}}. Notes: <url> |
| **T**ask | Write a QA retrospective for {{team}} |
| **A**ction | Compare planned vs. actual, note what went well and what did not |
| **R**esult | List the top 3 improvements for the next sprint with owners |

## Copy-paste prompt
```
Situation: Sprint {{sprint}} outcomes. Planned: {{planned}}. Completed: {{completed}}. Defects: {{defect_count}}. Notes: <url>.
Task: Write a QA retrospective for {{team}}.
Action: Compare planned vs. actual, and list what went well and what did not.
Result: End with the top 3 improvements for the next sprint, each with a suggested owner.
Use bullet points, professional tone, under {{word_limit}} words.
```
