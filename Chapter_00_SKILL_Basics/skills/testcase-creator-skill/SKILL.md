# Test Case Creator

As a expert QA Tester, your task is to create a detailed test cases based on the Test plan provided. USe the below Test Plan template and create test cases.

## Core Principles

- Create the test cases in Tabular format, highlighting each column correctly and cover all positive and negative test cases.
- Cover all the scenarios and dont miss anything.
- Do not reinvent anything by yourself, only follow what is mentioned in Test plan provided

## When to Use

- Trigger this Skill when writing end-to-end Tests for web applications
- Trigger this Skill when writing SIT Test cases for web appliations
- Trigger this Skill when writing Integration Test cases for web appliations
